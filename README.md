# GASR: Geometry-Aware 3D Super-Resolution

**진행 기간:** 2026년 8월 · *git 이력은 공개 시점의 단일 커밋부터 시작하며, 실제 작업 기간을 반영하지 않습니다.* · 다음 단계: [ROADMAP.md](ROADMAP.md)

**기하 인지 3D 초해상도 — 2D 초해상도 사전지식의 텍스처·형상 동시 전이** (연구 제안 초안 v1, 2026-08)

2D 영상 초해상도(SR)의 생성 사전지식을 텍스처(RGB)뿐 아니라 기하 채널(법선·깊이)에 동시에 전이하여, NeRF/3D Gaussian Splatting 장면의 **외관과 형상을 함께** 개선하는 프레임워크 제안.

## 핵심 아이디어
1. **X-SR** — RGB·법선·깊이를 한 묶음으로 업샘플하는 교차모달 SR 네트워크
2. **에피폴라 일관성 증류** — 뷰별 생성형 SR의 환각을 뷰 간 재투영 검증으로 걸러낸 뒤에만 3D에 반영
3. **음영 분해 손실** — 고주파 세부를 텍스처(알베도)와 미세 기하(법선) 중 물리적으로 옳은 쪽에 귀속

## 응용
국토교통부 **브이월드(V-World)** · 서울시 **S-Map** 공개 API의 저해상도 LoD 건물 메시/텍스처를 정련하여, 한국 도시 배경 **오픈월드 게임의 game-ready 맵**(충돌 메시·도로 네트워크·LoD 스트리밍 포함)과 디지털 트윈을 구축하는 파이프라인 설계 포함.
